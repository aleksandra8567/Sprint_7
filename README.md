В проекте написаны автотесты для API учебного сервиса Яндекс.Самокат.
Работа с курьерами :
1.Успешная регистрация курьера с обязательными полями.
2.Запрет дублирования курьеров (уникальный логин).
3.Обработка ошибок при отсутствии обязательных полей.
4.Авторизация существующего курьера с возвратом id.
5.Обработка неверных данных при входе.
6.Удаление курьера по id.
Работа с заказами :
1.Создание заказа с разными комбинациями цветов: BLACK, GREY, оба или ни одного.
2.Успешный ответ содержит уникальный track.
3.Принятие заказа курьером.
4.Получение заказа по track.
5.Получение списка всех заказов (поле orders в ответе).

Для запуска тестов:
pytest --alluredir=allure_results
